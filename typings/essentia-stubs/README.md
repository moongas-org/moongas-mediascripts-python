# Local Essentia stubs

This partial stub package is used by Pylance through the workspace's existing
`typings` stub path. It describes the installed Essentia `2.1b6.dev1438` API;
it does not replace or modify the runtime package.

The initial declarations were generated by Pylance. Essentia creates its
standard algorithm classes dynamically, so `standard.pyi` also includes the
runtime-discovered algorithm inventory. The MFCC extraction pipeline has typed
configuration parameters, positional inputs, NumPy float32 outputs, pool
aggregation, JSON output, and frame iteration.

Other algorithms remain declared but incompletely typed. Unstubbed modules
fall back to the installed package via the `partial` marker. This is not a
complete typing distribution for Essentia. When upgrading Essentia, compare
the runtime algorithm inventory and parameter metadata before updating these
declarations; ordinary static stub generation alone produces an empty
`standard.pyi`.

The generated partial declarations are excluded from direct workspace analysis,
but Pylance still uses them when checking imports in application code. Strict
checking remains enabled for the application.
